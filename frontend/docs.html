API Documentation

NexAPI is a gateway that proxies your requests to the real upstream API using your sub-API key. Your key is validated on every request — there is no rate limiting beyond your plan's request quota.

Introduction

After purchasing a plan you receive a unique sub-API key in the format NK-XXXXXXXX-XXXXXXXX-XXXXXXXX. Use this key instead of the real API key. The gateway validates it, swaps in the real key, and forwards your request — transparently.

Authentication

Pass your sub-API key in the key query parameter. If you would rather keep it out of the URL, the gateway also accepts it as an X-API-Key header or as Authorization: Bearer <key>.

QUERY PARAM
?key=NK-4F2A8C1D-9E7B3A2F-D6C5E4B1
HEADER
X-API-Key: NK-4F2A8C1D-9E7B3A2F-D6C5E4B1

Error Codes

      

        
STATUSERRORCAUSE

        
          
200—Success. The upstream response is returned as-is.

          
401API key requiredNo key parameter was provided.

          
401Malformed API keyWrong shape. A key is NK- plus three 8-character hex groups. Rejected before the upstream is called.

          
401Unknown API keyCorrectly formed, but not issued by this gateway.

          
401API key is inactiveDeactivated in the admin panel.

          
401API key expiredKey is past its expiry date. Buy a new plan.

          
429Request limit reachedYou used every request in your plan.

          
502Gateway errorThe upstream API could not be reached.

          
504Upstream timeoutThe upstream API did not answer in time.

        
      

      
Failed upstream calls (502 / 504) do not count against your quota.

      
Every error raised by this gateway carries "gateway": "NexAPI". If a response does not have it, it came from the upstream API and was passed through untouched.
